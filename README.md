# בית הזיכרונות של משה הלל ז״ל

אתר המשפחה לשיתוף באמצעות GitHub Pages.

המאגר מכיל אך ורק את הקבצים שנדרשים לתצוגת המבקרים. המחקר, מסך הניהול וחומרי העבודה נשמרים במאגר פרטי נפרד.

מקור התצוגה: `moshehillel2026/moshe-hillel-legacy`, ענף `premium-legacy-phase-2`.

**לפני הפעלה ראשונה:** יש להעלות לפה את קובץ הפורטרט המקורי בנתיב `assets/moshe-hillel-portrait.jpg` (אין ליצור תמונה חדשה). לאחר מכן מפעילים GitHub Pages מתוך Settings → Pages → Deploy from a branch → main → /(root).

אין להעלות למאגר הציבורי קבצי מחקר, תמונות משפחתיות פרטיות או חומרים שלא אושרו לשיתוף.
